# 시나리오 삽화 넣는 곳

여기에 이미지를 넣으면 진행자·학생 화면의 시나리오 카드에 뜹니다.

## 파일 이름

`content/scenarios.json` 의 `image` 값과 같은 이름이면 됩니다. **확장자는 아무거나** 괜찮습니다.

| 파일 이름 | 어디에 뜨는가 |
|---|---|
| `practice.*` | 연습 라운드 — 떡볶이 거스름돈 |
| `r1.*` | 라운드 1 — 급식 새치기 찬스 |
| `r2.*` | 라운드 2 — 심판의 유혹 |
| `r3.*` | 라운드 3 — 학급비의 비밀 |
| `r4.*` | 라운드 4 — 시험지 쪽지 |

`png` · `jpg` · `webp` · `gif` · `avif` · `svg` 를 읽습니다.
같은 이름이 여러 개면 **사진 형식이 svg 보다 먼저** 쓰입니다.

## 파일이 없으면

이모지와 색으로 그린 카드가 대신 뜹니다. 그대로 수업해도 됩니다.
이모지와 색은 `content/scenarios.json` 의 `emoji` · `tone` 으로 바꿀 수 있습니다.
(`tone` 은 `lime` `lilac` `cream` `mint` `pink` `coral` 중 하나)

## 크기

가로로 길쭉한 그림(2:1 ~ 16:9)이 잘 맞습니다. 폭 1200px 정도면 프로젝터에서 충분합니다.
파일은 서버가 직접 보내므로 인터넷 없이도 뜹니다. 너무 크면(5MB 이상) 학생 폰에서 느려집니다.
