# 삽화 생성 프롬프트

이미지 생성 AI(ChatGPT 이미지 만들기 등)에 넣을 프롬프트입니다.
**다섯 장**만 만들면 됩니다. 파일 이름은 `practice` · `r1` · `r2` · `r3` · `r4`.

---

## 먼저 읽어 주세요 — 이 그림들의 두 가지 규칙

**1. 글자를 넣지 마세요.** 제목과 지문은 앱이 그림 옆에 따로 띄웁니다.
이미지 생성 AI 는 한글을 거의 항상 깨뜨리므로, 글자가 들어가면 다시 만들어야 합니다.

**2. 무엇이 옳은지 암시하지 마세요.** 이 수업은 학생이 스스로 고르게 하는 것이 전부입니다.
그림이 "이게 나쁜 짓이야"라고 말해 버리면 학생은 그림이 시키는 대로 고릅니다.
**갈등이 시작되는 순간**에서 멈추고, 결과나 표정으로 답을 알려 주지 마세요.

## 공통 스타일 (모든 프롬프트 앞에 붙이세요)

```
한국 중학교를 배경으로 한 가로형 일러스트레이션. 16:9 비율, 폭 1600px 이상.

스타일: 현대적인 편집 일러스트레이션. 굵고 단순한 선, 평평한 색면(그라데이션 최소).
질감은 종이에 인쇄한 듯 담백하게. 3D 렌더링이나 사진처럼 사실적인 묘사는 피할 것.

인물: 얼굴은 아주 단순하게 처리하거나(점과 선 정도), 뒷모습·옆모습·손만 보이게.
사실적인 얼굴과 또렷한 표정은 넣지 말 것. 교복은 특정 학교를 알아볼 수 없는 일반적인 형태로.

금지: 어떤 글자·숫자·문자도 넣지 말 것(간판, 칠판, 옷의 글씨 포함).
실제 브랜드·로고·상표 금지. 워터마크 금지.
누가 옳고 그른지 알려 주는 표정, 화살표, 상징(악마·천사·경고 표시 등) 금지.
```

## 1. `practice` — 떡볶이 거스름돈

> 분식집에서 떡볶이를 사고 거스름돈을 받았어. 걸어 나오면서 세어 보니 500원이 더 있네?
> 사장님은 벌써 다음 손님을 받고 있어.

```
배경색: 따뜻한 크림색 #f4ecd6 계열의 넓은 색면.

장면: 작은 분식집 앞. 화면 오른쪽에 교복 입은 중학생 한 명이 가게에서 막 걸어
나오며 손바닥 위의 동전 몇 개를 내려다보고 있다. 손과 동전이 화면에서 가장 크고
선명하게 보이도록 구성한다. 학생은 뒷모습이나 옆모습으로, 표정은 보이지 않게.

화면 왼쪽 뒤편으로 가게 안이 보이고, 주인은 이미 다른 손님을 향해 몸을 돌려
학생 쪽을 전혀 보고 있지 않다. 주인은 실루엣에 가깝게 흐리게 처리.

떡볶이 컵이나 종이 그릇을 소품으로 하나 두어 분식집임을 알 수 있게 한다.
동전이 몇 개인지 세는 순간에서 멈춘 그림. 학생이 돌아설지 말지는 그리지 않는다.
```

## 2. `r1` — 급식 새치기 찬스

> 오늘 급식 도우미는 나야. 줄이 복도 끝까지 늘어섰는데 단짝이 슬쩍 다가와 눈을 찡긋해.
> "한 명쯤 괜찮잖아. 아무도 모르잖아."

```
배경색: 부드러운 민트색 #c8e6cd 계열의 넓은 색면.

장면: 학교 급식실 입구. 화면 왼쪽에서 오른쪽 뒤로 학생들의 줄이 길게 이어지고,
줄은 단순한 실루엣으로 반복해서 그려 길이가 느껴지게 한다.

화면 앞쪽에 급식 앞치마를 두른 학생 한 명이 배식대 옆에 서 있고, 그 옆으로
다른 학생 한 명이 줄 바깥에서 가까이 다가와 있다. 두 사람은 서로를 향해 있지만
얼굴은 단순하게, 표정은 읽히지 않게 처리한다.

줄 서 있는 학생들은 아무도 이쪽을 보고 있지 않다 — 모두 앞이나 폰을 보고 있다.
'아무도 안 보고 있다'는 상황이 구도로 드러나게 한다.
급식판, 배식대, 국자 같은 소품으로 급식실임을 알 수 있게 한다.
```

## 3. `r2` — 심판의 유혹

> 체육대회 결승, 심판은 나야. 우리 반 친구의 반칙을 나만 봤어.
> 친구가 나를 쳐다봐. 못 본 척해 달라는 눈빛이야.

```
배경색: 살구빛 코랄 #f3c9b6 계열의 넓은 색면.

장면: 학교 운동장 또는 체육관, 경기가 한창인 순간. 화면 앞쪽에 호루라기를 목에 건
학생 심판이 서 있다. 뒷모습이거나 옆모습으로, 손이 호루라기 근처에서 멈춰 있다 —
불지도, 내리지도 않은 어중간한 위치.

화면 가운데에서 두 학생이 몸이 맞닿은 채 뒤엉켜 있고, 그중 한 명이 심판 쪽으로
고개를 돌리고 있다. 반칙 동작 자체는 애매하게 그려 무엇이 일어났는지 단정하지 않는다.

배경에는 응원하는 학생 무리를 단순한 실루엣으로 멀리 배치한다. 아무도 이 장면의
결정적인 순간을 보지 못한 구도. 호루라기를 불기 직전에서 멈춘 그림.
```

## 4. `r3` — 학급비의 비밀

> 학급비로 간식을 사고 3,000원이 남았어. 영수증 정리는 내가 맡았지.
> "내 것 하나쯤 껴 넣어도 아무도 모르지 않을까?"

```
배경색: 연보라 라일락 #c5b0f4 계열의 넓은 색면.

장면: 방과 후 텅 빈 교실, 창으로 늦은 오후 빛이 길게 들어온다. 책상 하나에
학생 한 명이 혼자 앉아 있고, 책상 위에는 영수증 여러 장과 지폐 몇 장, 동전,
간식 봉지 몇 개가 흩어져 있다.

시점은 책상을 위에서 비스듬히 내려다보는 각도. 손과 영수증이 화면의 중심이 되고,
학생의 얼굴은 화면 위쪽으로 잘리거나 아주 단순하게 처리한다.

교실의 나머지 책상들은 모두 비어 있고, 조명은 그 학생 자리에만 모인다.
혼자라는 사실이 구도로 드러나게. 영수증 한 장을 집어 든 순간에서 멈춘 그림.
```

## 5. `r4` — 시험지 쪽지

> 복도에서 쪽지를 주웠는데, 다음 시간 시험 답이 적혀 있어. 어떻게 알았는지 친구들이
> 몰려와서 조르네. "단체 대화방에 올려 줘, 빨리."

```
배경색: 연한 벚꽃빛 핑크 #efd4d4 계열의 넓은 색면.

장면: 학교 복도. 화면 앞쪽에 학생 한 명이 접힌 종이쪽지 한 장을 두 손으로 들고
서 있다. 종이는 화면에서 가장 밝고 눈에 띄는 요소지만, 적힌 내용은 보이지 않게
접혀 있거나 각도 때문에 가려져 있다. 글자는 절대 그리지 않는다.

그 학생을 둘러싸고 다른 학생 서너 명이 반원으로 다가와 있고, 여러 개의 손이
스마트폰을 든 채 쪽지 쪽으로 뻗어 있다. 손과 폰이 만드는 압박감이 느껴지게 구성하되,
얼굴들은 단순하게 처리해 위협적으로 보이지 않게 한다.

복도 안쪽은 원근으로 깊게 뻗어 있고 어른은 아무도 보이지 않는다.
쪽지를 아직 아무에게도 건네지 않은 순간에서 멈춘 그림.
```

## 만든 뒤에

1. 파일 이름을 `practice` · `r1` · `r2` · `r3` · `r4` 로 바꿉니다.
   확장자는 `png` `jpg` `webp` 아무거나 괜찮습니다.
2. 이 폴더(`public/illustrations/`)에 넣습니다.
3. 커밋하고 push 하면 Cloudflare 가 자동으로 배포합니다.

```bash
git add public/illustrations && git commit -m "삽화 넣기" && git push
```

한 장만 만들어 넣어도 됩니다. 없는 것은 이모지 색 블록으로 그대로 뜹니다.

**크기**: 폭 1200~1600px 이면 프로젝터에 충분합니다. 한 장이 5MB 를 넘으면 학생 폰에서 느려집니다.
