# 🏘️ 신뢰마을 (Trust Village)

중학교 한 학급(20~34명)이 60분 수업 동안 함께하는 **실시간 게임 웹앱**.
"들키지 않으면 괜찮을까?"를 몸으로 겪게 하는 도덕·사회 수업 도구입니다.

주소 하나면 됩니다. 학생은 **폰 브라우저로 QR을 찍고 들어옵니다** — 로그인도, 앱 설치도 없습니다.

**Cloudflare Workers + Durable Objects** 위에서 돕니다.

전체 명세는 [CLAUDE.md](CLAUDE.md) 참고.

---

## 배포

Cloudflare Workers 에 올립니다. 길은 두 가지이고, 결과는 같습니다.

### 방법 1 — 내 컴퓨터에서 올리기 (한 번만 급히 올릴 때)

```bash
npm install
```

```bash
npx wrangler login
```

브라우저가 한 번 열립니다(Cloudflare 계정 승인). 그 다음:

```bash
npm run deploy
```

끝입니다. `https://trust-village.<계정>.workers.dev` 주소가 나옵니다.

### 방법 2 — GitHub 에 올리면 Cloudflare 가 알아서 (Workers Builds) ← 이 저장소가 쓰는 방식

`main` 에 push 할 때마다 자동으로 배포됩니다. 대시보드에서 **한 번만** 연결하면 끝입니다.

**Cloudflare 대시보드 → Compute (Workers) → Create → Import a repository**
→ GitHub 계정 승인 → `village` 저장소 선택

| 항목 | 값 |
|---|---|
| Project name | `trust-village` |
| Production branch | `main` |
| Build command | `npm run fonts` |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/` |
| 환경변수 | **없음** |

`wrangler.jsonc` 안에 이름·진입점·Durable Object·정적 파일이 모두 적혀 있어서
대시보드에서 따로 지정할 것이 없습니다. Durable Object 는 첫 배포 때 `migrations` 를
보고 자동으로 만들어집니다.

Build command 의 `npm run fonts` 는 안전장치입니다. 폰트는 원래 `npm install` 이
알아서 만들지만(`postinstall`), 빌더가 설치 스크립트를 건너뛰더라도 글꼴이 빠지지
않도록 한 번 더 시킵니다. 여러 번 돌려도 결과는 같습니다. 비워 둬도 됩니다.

> ⚠️ **`npx wrangler deploy` 를 Build command 칸에 넣지 마세요.**
> Cloudflare 는 배포용 API 토큰을 **Deploy command 단계에만** 넣어 줍니다.
> Build command 자리에서 돌리면 이렇게 실패합니다:
>
> ```
> ERROR  In a non-interactive environment, it's necessary to set a
>        CLOUDFLARE_API_TOKEN environment variable for wrangler to work.
> Failed: build command exited with code: 1
> ```
>
> **API 토큰을 직접 만들 필요는 없습니다.** Cloudflare 가 계정에 맞춰 알아서
> 발급하고 계속 씁니다. 위 에러가 났다면 토큰이 아니라 **칸이 잘못된 것**입니다.
>
> 만들 때 **Pages 가 아니라 Workers** 로 만들었는지도 확인하세요. Pages 프로젝트에는
> Deploy command 칸 자체가 없어서 같은 에러가 납니다. 이 앱은 Durable Objects 를
> 쓰므로 Worker 여야 합니다.

**첫 배포 뒤 확인할 것**

1. `https://trust-village.<계정>.workers.dev/host` 가 열리는지
2. `수업 만들기` 를 눌러 QR 과 6자리 코드가 나오는지
3. QR 아래 안내가 **"어디서든 이 주소로 들어올 수 있어요."** 로 뜨는지
   (`localhost` 가 아니라 배포 주소로 인식됐다는 뜻입니다)
4. 폰으로 QR 을 찍어 별명과 마을이 배정되는지

**삽화**(`public/illustrations/`)는 저장소에 함께 커밋해야 배포에 실려 갑니다.
파일을 넣고 `git add public/illustrations && git commit && git push` 하면 됩니다.
없으면 이모지로 대신 뜨므로 수업은 그대로 돌아갑니다.

### 올리고 나면

- 진행자: `https://주소/host`
- 학생: `https://주소` (QR 로 바로)

**설정할 환경변수가 없습니다.** 진행자가 접속한 주소를 서버가 그대로 읽어 QR을 만들기 때문에,
`workers.dev` 든 직접 연결한 도메인이든 알아서 맞습니다.

### 요금

Durable Objects 는 SQLite 저장소를 쓰므로 **무료 요금제에서 동작**합니다.
한 학급 34명이 60분 수업 한 판을 하는 정도는 무료 한도 안에 넉넉히 들어갑니다.

### 왜 Workers 인가

실시간 게임이라 WebSocket 이 계속 열려 있어야 하고, 수업 하나마다 상태가 있어야 합니다.
**Durable Object 하나가 수업 하나**를 맡습니다 — 그 안에 상태와 연결이 함께 있어서
방을 나누거나 서버 여러 대를 맞출 일이 없습니다.

- 잠들지 않습니다. 첫 요청부터 바로 뜹니다.
- 상태는 Durable Object 저장소에 남습니다. 재시작해도 수업이 이어집니다.
- 라운드 시계는 DO 알람이라, 조용한 사이에도 제시간에 마감됩니다.

### 내 컴퓨터에서

```bash
npm run dev
```

`http://localhost:8787/host` 로 열립니다. 배포된 것과 **같은 코드, 같은 런타임**입니다.

> **OneDrive·Dropbox 폴더에서 작업할 때**: 동기화가 파일을 건드릴 때마다
> `wrangler dev` 가 재시작해서 수업이 끊깁니다. 개발·시연은 동기화 폴더 밖에서 하세요.

## 구조

```
worker/     Cloudflare 진입점
  index.js       정적 파일 · /api/* · /ws 를 Durable Object 로
  session-do.js  수업 하나 = Durable Object 하나 (상태 · WebSocket · 저장)
  qr.js          QR (SVG, 순수 JS)
shared/     런타임과 무관한 게임 두뇌 — Node 에서도 Workers 에서도 그대로 돈다
  game/     session(상태) · stages(상태머신) · engine(라운드) · demo(봇)
  lib/      nickname · code · clean(금칙어)
  content.js  content/ JSON 을 읽어 들이는 곳
public/     빌드 도구 없는 순수 HTML/CSS/JS (Workers Assets 가 서빙)
content/    시나리오·워밍업·이야기·제도 JSON (교체 가능)
tools/      점검 스크립트
```

게임 규칙은 전부 `shared/` 안에 있고 Node 의존이 하나도 없습니다.
그래서 규칙 검증(`smoke:engine`)은 서버 없이 그냥 `node` 로 돕니다.

## 수업 당일

주소 두 개면 됩니다. 같은 앱이고, 붙는 화면만 다릅니다.

| 누가 | 어디로 | 무엇으로 |
|---|---|---|
| **진행자** | `https://주소/host` | 노트북 → 프로젝터 |
| **학생** | `https://주소` | 폰 브라우저 (QR 찍으면 코드까지 자동) |

학생은 아무것도 설치하지 않고, 아무것도 입력하지 않습니다. 이름도 묻지 않습니다.

### 순서

1. **노트북에서 `/host` 를 열고 프로젝터에 띄웁니다.**
2. **마을 수 · 라운드 시간을 고르고 `수업 만들기`.**
   기본값은 마을 4개 · 60초입니다. 마을당 6~9명이 알맞으니 30명이면 4개가 맞습니다.
3. **QR 과 6자리 코드가 뜹니다.** 크게 띄워 두면 학생들이 찍고 들어옵니다.
   들어온 인원과 마을 배정이 실시간으로 채워집니다. 배정은 들어온 순서대로 돌아가며 이루어집니다.
4. **`다음 →` 으로 단계를 넘깁니다.** 키보드 `→` 나 프레젠테이션 리모컨도 됩니다.
   라운드에서는 버튼 글씨가 `라운드 시작 →` / `지금 마감 →` / `다음 →` 으로 바뀌며 알려 줍니다.
5. **마무리 단계에서 `결과 CSV 내려받기`.** 마을·라운드 단위 집계만 들어 있습니다.

### 수업 중에 알아 두면 좋은 것

- **늦게 온 학생**도 코드만 넣으면 진행 중인 단계에 바로 합류합니다.
- **폰이 잠기거나 새로고침해도** 같은 별명·같은 마을로 돌아옵니다.
- **진행자 화면을 새로고침해도** 하던 수업으로 자동 복귀합니다. 코드를 다시 만들 필요가 없습니다.
- **시간이 모자라면** `+30초`, **다들 빨리 냈으면** `지금 마감`.
  전원이 제출하면 시간이 남아도 알아서 마감됩니다.
- **제출 인원은 숫자만** 보입니다. 누가 냈는지, 무엇을 냈는지는 진행자 화면에도 나오지 않습니다.

### 수업 전에 한 번 돌려 보기

설정에서 **데모 봇 `28명 자동 입장`** 을 켜면 가상 학생이 알아서 움직입니다.
혼자서 처음부터 끝까지 눌러 보며 흐름을 익힐 수 있습니다. 수업 중에도 켜고 끌 수 있습니다.

## 수업 흐름

```
입장 대기 → 워밍업 → 기게스의 반지 → 규칙 → 연습
         → R1 → R2 → 중간 집계 → 마을회의 → R3 → R4
         → 최종 발표 → 소감 → 서약 → 마무리
```

단계 전진은 **진행자의 "다음" 버튼**으로만 일어납니다.
키보드 `→` / `←` 또는 프레젠테이션 리모컨으로도 넘길 수 있습니다.

### 라운드에서 "다음" 버튼의 뜻

라운드 단계에서는 "다음"이 국면에 따라 세 가지로 갈립니다. 버튼 글씨가 알려 줍니다.

| 국면 | 버튼 | 하는 일 |
|---|---|---|
| 설명 중 | `라운드 시작 →` | 시나리오를 읽어 준 뒤 타이머를 시작 |
| 진행 중 | `지금 마감 →` | 시간이 남아도 바로 마감하고 집계 |
| 마감됨 | `다음 →` | 다음 단계로 |

라운드가 도는 동안 진행자 화면에서 **`+30초`** 로 시간을 늘리거나,
**`다시`** 로 모은 선택을 **점수에 넣지 않고** 되돌릴 수 있습니다.
전원이 제출하면 시간이 남아도 자동으로 마감됩니다.

### 최종 발표

발표는 **`공개 →`** 를 누를 때마다 한 장씩 열립니다. 다음에 무엇이 나오는지는
버튼 왼쪽에 미리 적혀 있어서, 뜸을 들이거나 질문을 던질 여유가 생깁니다.

1. **개인 코인 TOP 3** — 익명 별명으로
2. **마을별 코인** — "코인이 많은 마을이 신뢰도 높을까요?"
3. **마을 신뢰지수 순위** — 최종 순위. 코인 1위 마을의 신뢰 순위가 낮으면 그 자리에서 짚어 줍니다
4. **라운드별 정직 선택률** — 마을회의 시점에 세로 표시선이 그어집니다

네 장이 다 열리면 버튼이 `다음 →` 으로 바뀝니다.

## 혼자 확인해 보기 — 데모 봇 모드

학생 없이 수업 한 판을 통째로 돌려 볼 수 있습니다. 리허설이나 시연용입니다.

**수업 만들기 화면**에서 `데모 봇 → 28명 자동 입장`을 고르거나,
수업 중 아무 때나 진행자 화면 오른쪽 위 **`데모 봇`** 버튼을 누르면 됩니다.
가상 학생 28명이 들어와 단계마다 알아서 움직입니다 — 워밍업 투표, 라운드 선택,
마을회의 제도 투표, 소감 쓰기와 하트, 서약까지.

**`데모 끄기`** 를 누르면 봇과 봇이 남긴 것이 전부 사라집니다. 사람 학생은 그대로 남습니다.

### 봇이 고르는 방식

시연에서 곡선이 매번 읽히도록 분포를 설계했습니다.

| 라운드 | 봇의 성향 | 정직 선택률(대략) |
|---|---|---|
| 연습·R1·R2 | **몰래 이득이 다수** — 들키지 않으면 괜찮아 보이는 구간 | 30~40% |
| R3·R4 | 중간 집계를 보고 돌아서고, **제도가 밀어 올린다** | 60~85% |

제도별로 미는 힘이 다릅니다 — 감사제(가장 큼) · 장부제 · 서약제 순.
몇 명은 일부러 제출하지 않아, 미제출자가 있는 실제 교실 모습도 함께 나옵니다.

봇은 서버 안(그 수업의 Durable Object)에서 돕니다. 터미널을 열 필요가 없습니다.

## 점검 스크립트

게임 규칙만 확인 (아무것도 안 띄워도 됨):

```bash
npm run smoke:engine
```

배포되는 코드 전체 — 다른 터미널에서 `npm run dev` 를 켜 두고:

```bash
npm run smoke:worker
```

실제 배포 주소를 두드려 보려면:

```bash
TV_URL=https://주소 npm run smoke:worker
```

| 스크립트 | 보는 것 | 필요한 것 |
|---|---|---|
| `smoke:unit` | 마을 배정 · 상태 직렬화 | 없음 |
| `smoke:engine` | 신뢰지수 계산 · 제도 효과 · **익명성** | 없음 |
| `smoke:worker` | 수업 한 판 통째로 — 세션·QR·라운드·마을회의·발표·소감·서약·CSV | `npm run dev` |

`smoke:worker` 는 브라우저와 똑같은 WebSocket 규약으로 두드리므로,
**배포될 코드 그 자체**를 확인합니다.

## 개인정보에 대해

- 이름·학번·전화번호·로그인 **없음**. 학생은 서버가 지어 준 익명 닉네임(`용감한 수달`)뿐입니다.
- **누가 무엇을 골랐는지는 저장하지 않습니다.**
  개인의 선택은 라운드가 열려 있는 동안에만 서버 메모리에 있고,
  마감하는 순간 마을별 카운트로 접힌 뒤 **원본이 즉시 지워집니다.**
- 진행자 화면에 나가는 값에는 개인의 선택이 아예 들어 있지 않습니다. **제출 인원 수만** 보입니다.
- 저장소(Durable Object)에 남는 것은 마을별 `{a, b, c}` 개수뿐입니다.
- 학생 본인은 자기 선택을 볼 수 있지만, 그 값은 그 학생의 소켓으로만 나갑니다.

`npm run smoke:engine` 의 "익명성" 항목이 이 규칙들을 매번 검사합니다.

## 데이터

수업 상태는 그 수업의 Durable Object 안에 있고, 단계가 바뀔 때마다 저장소에 남습니다.
서버가 다시 뜨거나 잠들었다 깨어나도 수업이 그대로 이어집니다.
12시간이 지난 세션은 스스로 만료됩니다.

> **진행 중인 라운드**도 이어집니다. 다만 개인의 선택은 그 라운드가 살아 있는 동안만
> 따로 보관되고, **마감하는 순간 통째로 지워집니다.** 수업 기록(집계·CSV)에는
> 어떤 경로로도 들어가지 않습니다.

## 콘텐츠 바꾸기

수업 내용은 `content/` 안의 JSON만 고치면 바뀝니다. 서버 코드는 건드릴 필요가 없습니다.

- `content/scenarios.json` — 연습 + 4개 라운드 시나리오 (제목·지문·선택지 3개·삽화 경로)
- `content/warmup.json` — 여는 투표 2문항
- `content/story.json` — 기게스의 반지 3컷
- `content/institutions.json` — 마을회의 제도 카드 3종

### 삽화 넣기

`public/illustrations/` 에 `practice` · `r1` · `r2` · `r3` · `r4` 이름으로 이미지를 넣으면
시나리오 카드에 뜹니다. **확장자는 아무거나** 됩니다 — `png` `jpg` `webp` `gif` `avif` `svg`.
서버가 이름으로 찾아 주므로 `content/scenarios.json` 은 건드릴 필요가 없습니다.
같은 이름이 여럿이면 사진 형식이 `svg` 보다 먼저 쓰입니다.

**파일이 없으면 이모지와 색으로 그린 카드가 대신 뜹니다.** 그대로 수업해도 됩니다.
이모지와 색은 `scenarios.json` 의 `emoji` · `tone` 으로 바꿉니다
(`tone`: `lime` `lilac` `cream` `mint` `pink` `coral`).

자세한 것은 [public/illustrations/README.md](public/illustrations/README.md) 참고.

### 결과 CSV

진행자 화면 오른쪽 위 **`CSV`** 버튼에서 언제든 받을 수 있습니다. 들어가는 것:

| 구간 | 내용 |
|---|---|
| 라운드별 · 마을별 | 인원 · 제출 · 미제출 · a/b/c 개수 · 정직 선택률 · 신뢰지수 변화 · 적발/보너스 인원 |
| 라운드별 학급 전체 | 라운드마다 학급 전체 합계 |
| 마을 최종 | 신뢰지수 순위 · 채택 제도 · 마을 코인 합계 |
| 워밍업 | 보기별 표수 |
| 마무리 | 참여·서약 인원, 소감 수와 하트 합계, 익명 소감 원문 |

**개인 단위 행은 어떤 형태로도 들어가지 않습니다.** 익명 별명조차 넣지 않았습니다 —
별명이라도 한 사람에 한 줄이면 개인 단위이기 때문입니다. 집계의 가장 작은 단위는 **마을**입니다.

## 마을회의와 제도

2라운드가 끝나면 마을마다 제도 하나를 **다수결로** 채택합니다. 득표가 바뀌면 채택 제도도
바로 바뀌고, **동점이면 카드 순서상 앞선 것**(투명 장부제 → 청렴 감사제 → 청렴 서약제)이 뽑힙니다.
채택된 제도는 **3·4라운드에만** 적용됩니다.

| 제도 | 3·4라운드에서 실제로 하는 일 |
|---|---|
| 📖 투명 장부제 | 라운드가 도는 동안 **우리 마을** 선택 비율(a/b/c %)이 그 마을 학생들에게만 실시간으로 보입니다. 누가 골랐는지는 여전히 안 보입니다. |
| 🔍 청렴 감사제 | `몰래 이득`을 고르면 40% 확률로 적발돼 코인 −4. 결과적으로 +3−4 = **−1**. **적발 사실은 그 학생 화면에만** 뜹니다 — 진행자 화면에도, 집계에도, CSV에도 "적발 인원 수"만 남습니다. |
| ✋ 청렴 서약제 | 라운드가 **시작되기 전에** 서약을 누른 학생이 `규칙대로`/`용기 내어 알리기`를 고르면 코인 +1. 서약해 놓고 어겨도 벌은 없습니다. |

## 소감과 서약

- 소감은 **익명**이고 **100자**까지, 한 사람이 **3개**까지 쓸 수 있습니다. 카드에는 글·하트 수·시각만 남고 작성자 정보는 어디에도 없습니다.
- 간단한 **금칙어 필터**가 있습니다([shared/lib/clean.js](shared/lib/clean.js)). 사이에 낀 공백·기호(`시 발`, `시*발`)도 함께 걸러 냅니다. 걸리면 조용히 지우지 않고 학생에게 다시 쓰라고 알려 줍니다.
- 하트는 한 사람이 한 장에 하나이고, 다시 누르면 취소됩니다.
- 서약은 진행자 화면의 게이지가 차오르며 인원이 올라갑니다.

## 디자인

흑백 편집 지면 위에 커다란 파스텔 색 블록을 얹는 방식입니다.
버튼·본문·라벨은 철저히 검정과 흰색이고, 이야기가 있는 자리(마을·시나리오·발표 카드)에만 색이 들어갑니다.

- 위계는 크기보다 **굵기**가 만듭니다. 중간 회색 글자는 쓰지 않습니다.
- 모든 CTA 는 알약(pill), 아이콘 버튼은 원입니다. 각진 버튼은 없습니다.
- 마을 색은 글자에 쓰지 않고 **면**으로만 씁니다. 색 위 글자는 언제나 검정입니다.
- 그림자 대신 색이 깊이를 만듭니다. 흰 카드는 머리카락 굵기 선 한 줄로 세웁니다.
- 색 블록 사이에는 흰 지면을 넉넉히 둡니다.

색·글자·간격·모서리 토큰은 [public/css/base.css](public/css/base.css) 한 곳에 모여 있습니다.

### 글꼴

**Pretendard Variable**(본문·제목)과 **JetBrains Mono Variable**(라벨·숫자·코드) 두 가지이며,
둘 다 OFL 라이선스입니다. CDN 을 쓰지 않고 `npm install` 시 `public/fonts/` 로 복사되어
우리 서버가 직접 서빙합니다 — CDN 을 기다리지 않아 첫 화면이 빨리 뜹니다.

한글은 글자 수가 많아 통짜로 받으면 2MB 라, 유니코드 구간별로 쪼갠 동적 서브셋을 씁니다.
브라우저가 화면에 실제로 뜬 글자에 해당하는 조각(조각당 약 34KB)만 받아 갑니다.

폰트를 다시 복사하려면:

```bash
npm run fonts
```

### 프로젝터 글자 크기

진행자 화면은 화면 폭에 따라 `--scale` 이 커집니다 (1280px 에서 1.0, 2200px 이상에서 1.5).
제목은 86px × 배율이라 1080p 프로젝터에서 약 98px — 교실 뒷자리에서 읽히는 크기입니다.
